Baseline Comparison

同一组图片下，对比传统密文外观、经典 LSB 隐写和本系统

对比脚本使用 3 张目标图、同一张原始载体和同一张系统隐写载体计算平均指标。传统密文行只用于说明密文外观， 不比较 AES 等标准算法的密码强度；LSB 行作为经典单图隐写基线，用来说明载体不可感知性和容量/权限能力差异。

方法 参考依据 载体 PSNR / SSIM 恢复 PSNR / SSIM 说明
Noise-cipher baseline NIST FIPS 197, AES - 8.48 / 0.0079 噪声密文外观明显，适合作为“可见密文”对照。
LSB steganography baseline Chan & Cheng, 2004 62.40 / 0.9997 - 载体扰动极小；该行只作为普通隐写不可感知性对照。
AMP-CS system Candes et al., 2006; Donoho, 2006 51.15 / 0.9985 36.22 / 0.9591 保持载体自然外观，同时支持授权恢复多张目标图。
Wrong-key ablation 本项目消融实验 - 5.62 / 0.0027 错误置乱索引下恢复失败，说明密钥/索引敏感。

Reconstruction Baselines

同条件对比 SPL、OMP 与 AMP-Net 的重建质量和时间

三种方法使用同一批 3 张目标图、同一个 60% 采样矩阵和 33 x 33 分块。该对比用于说明： 项目采用 AMP-Net 不是只为了提高画质，也为了替代传统迭代重建在交互演示中的时间开销。

重建方法 实验条件 总时间 平均时间/图 PSNR SSIM 结论
SPL-style 80 次迭代，DCT 阈值约束 1.80s 0.60s 22.09 0.4889 速度尚可，但恢复噪声明显。
OMP-DCT 每块最多 60 个 DCT 原子 44.94s 14.98s 28.17 0.7830 质量优于 SPL-style，但耗时较高。
AMP-Net 本项目模型输出，9 个 phase 1.49s 0.50s 36.22 0.9591 质量和速度综合表现最好。
