# 大创答辩要点

## 一句话介绍

本项目实现了一个基于压缩感知与隐写融合的多级图像安全传输 demo：系统将多幅图像的压缩测量信息隐藏进一张视觉正常的载体图，并根据用户权限恢复不同内容。

## 推荐展示顺序

1. 访客视图：只看到视觉正常的隐写载体图，说明“隐藏信息存在性”不容易暴露。
2. A 用户视图：恢复目标图，并展示低权限场景下的 AI 隐私保护。
3. B 用户视图：恢复源图和目标图，体现完整授权访问。
4. 错误密钥实验：使用错误置乱索引后恢复失败，体现密钥敏感性。
5. 指标表：展示目标图/源图 PSNR、SSIM、载体相似度和端到端运行时间。

## 可以强调的创新点

- 把压缩感知、矩阵加密、DCT 隐写和分级权限控制组合成完整可运行链路。
- 输出载体视觉正常，相比传统噪声密文更适合隐蔽传输演示。
- 使用 AMP-Net 改善压缩感知重建质量，让本科 demo 展示更稳定。
- 引入 YOLO 隐私保护模块，让低权限用户“能看但不完全暴露敏感信息”。

## 需要主动说明的边界

- 当前是软件原型，压缩采样由软件模拟，尚未接入真实硬件采样端。
- 隐写模块主要面向演示场景，复杂网络传输下的压缩、裁剪、噪声鲁棒性仍可继续增强。
- 演示账号密码是本地 demo 凭据，不代表真实生产系统的密钥管理方案。
- 模型权重、结项书和完整输出结果未上传 GitHub，公开仓库只保留核心代码和展示材料。
